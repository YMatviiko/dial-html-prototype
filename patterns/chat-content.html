Create plot of sin(x* 4.5) in Plotly

If you run this code in your local Python environment (after installing plotly and kaleido), you will get the chart:

Python 
import numpy as np
import plotly.graph_objs as go

x = np.linspace(0, 2 * np.pi, 500)
y = np.sin(x * 4.5)

trace = go.Scatter(x=x, y=y, mode='lines', name='sin(x*4.5)')
layout = go.Layout(title='Plot of sin(x*4.5)', xaxis=dict(title='x'), yaxis=dict(title='sin(x*4.5)'))
fig = go.Figure(data=[trace], layout=layout)
fig.show()
